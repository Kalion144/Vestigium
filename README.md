# VESTIGIUM - versão Java

Conversão do projeto original em C para Java, mantendo textos, layout de terminal, regras, probabilidades, atributos, itens, efeitos, combate, progressão e história.

## Compilar

No diretório do projeto:

```bash
javac -encoding UTF-8 Main.java Tela.java Menu.java Creditos.java Informacoes.java Jogo.java Combate.java personagens/*.java mecanicas/ataques/*.java mecanicas/efeitos/*.java mecanicas/evolucao/*.java mecanicas/itens/*.java
```

## Executar

```bash
java Main
```
